# Programme C204 — Transcriptions révisées (Équipe A)

Version 1.1 — 10 novembre 2026 (corrections post-validation n° 7, 12, 13 et 14). Remplace le §3 du dossier de base.

Tout ce qui suit est **[DOC]** au sens du dossier de base : « voici ce qui est écrit sur l'image », jamais
« voici ce qui est vrai ». Les lectures ont été faites à l'œil sur les meilleures copies (voir INVENTAIRE.md),
agrandies par simple interpolation (`ameliores/alt_*.png`) ; aucune reconnaissance automatique de caractères
ni restauration générative n'a été utilisée.

Échelle de confiance par ligne : **É** = élevée (chaque lettre lisible) · **M** = moyenne (mot reconnaissable,
quelques lettres devinées) · **F** = faible (lecture en partie conjecturale). Colonne « Base » : ✔ = lecture du
dossier de base confirmée ; ✎ = corrigée ; ＋ = ajoutée.

Deux aides objectives ont servi pour les mots abîmés de DOC-008 : (1) la police est à chasse fixe (pas mesuré :
5,87 px par caractère sur `PT4.jpg`), ce qui donne le **nombre de lettres** de chaque mot ; (2) la **corrélation
d'image** entre un mot douteux et le même mot lisible ailleurs sur la page.

Témoin d'époque : le 23 novembre 2000, un membre du forum a recopié la légende de DOC-008 telle qu'il la lisait
sur le fichier d'origine, et l'auteur a répondu « That looks correct » (fil « Time-travel Paradoxes », messages
nᵒˢ 95 et 96, `sources_web/tti/tti_t14274.txt`). Cette lecture est citée ci-dessous sous le nom « lecteur de 2000 ».
