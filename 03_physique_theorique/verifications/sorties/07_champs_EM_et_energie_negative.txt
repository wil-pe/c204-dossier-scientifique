  ds² = Λ²(-dt² + dρ² + dz²) + ρ²/Λ² dφ²,  Λ = 1 + B²ρ²/4,  A_φ = Bρ²/(2Λ)
  R_{μν} - 2(F_{μα}F_ν^α - ¼ g_{μν}F²) = 0 (vérifié)

[E5] Bulle d'Alcubierre : densité d'énergie eulérienne par la contrainte hamiltonienne (tranches plates)
  ρ_E = (K² - K_ij K^ij)/16π = v**2*(-y**2 - z**2)*Subs(Derivative(f(_xi_1), _xi_1), _xi_1, sqrt(x**2 + y**2 + z**2))**2/(32*pi*(x**2 + y**2 + z**2))
   = -(v²/32π) (y² + z²)/r² (df/dr)²  ≤ 0 partout  (Alcubierre 1994)
  intégrale : E = -(v²/12) ∫ r² f'(r)² dr ; profil linéaire d'épaisseur Δ : E = -(v²/12)(R²/Δ + Δ/12)   [G = c = 1]
   contrôle : ∫ r² f'² dr = Delta/12 + R**2/Delta
  R = 3.7 m, Δ = 1 m, v = c : E = -1.39e+44 J = -1.55e+27 kg = -7.77e-04 M_soleil
  R = 3.7 m, Δ = 0.01 m, v = c : E = -1.38e+46 J = -1.54e+29 kg = -7.73e-02 M_soleil
  R = 3.7 m, Δ = 1.62e-33 m, v = c : E = -8.54e+76 J = -9.50e+59 kg = -4.78e+29 M_soleil
