  R_{μν} - 2(F_{μα}F_ν^α - ¼ g_{μν}F²) = 0 (vérifié, les 10 composantes)
  det g = -(a**2*x**2 + r**2)**2   -> sqrt(-g) = Σ (en coordonnée x = cos θ)
  ∂_μ(√-g F^{μν}) = [0, 0, 0, 0] (équations de Maxwell sans source)

[A4] Horizons, ergosphère, thermodynamique (unités géométriques)
  r± = M ± sqrt(M² - a² - Q²) ; r+ r- = a² + Q² ; r+ + r- = 2M
  d r-/dQ = Q/sqrt(M**2 - Q**2 - a**2)  (> 0 : ajouter de la charge agrandit l'horizon interne)
  d r+/dQ = -Q/sqrt(M**2 - Q**2 - a**2)  (< 0 : et réduit l'horizon externe)
  ergosphère (g_tt = 0) : r_E(θ) = M + sqrt(M² - Q² - a² cos²θ)
   contrôle : -g_tt Σ = -2*M*r + Q**2 + a**2*x**2 + r**2
  aire A = 4π(r+² + a²) ; gravité de surface κ = (r+ - r-)/(2(r+² + a²)) ; T = κ/2π (-> 0 à l'extrémalité)
   contrôle Schwarzschild : κ = 1/(4*M) (= 1/4M)
  masse irréductible M_irr² = A/16π :
   Kerr extrémal (a=M, Q=0)  : M_irr/M = sqrt(2)/2 -> énergie de rotation extractible ≤ 29.3 %
   RN extrémal (Q=M, a=0)    : M_irr/M = 1/2 -> énergie électrostatique = 50 % de M c²
  [temps écoulé 21 s]

[A5] Aucune anomalie causale hors de l'horizon externe : t est une fonction de temps globale pour r > r+
  g^{tt} = -N/(ΔΣ) avec N = (r²+a²)² - Δ a² sin²θ = r²(r²+a²) + a²(2Mr - Q²) + Δ a² cos²θ : identité vérifiée
  pour r > r+ : Δ > 0 et 2Mr - Q² > 2M r+ - Q² = r+² + a² > 0, donc N > 0 et g^{tt} < 0 :
  le gradient de t est partout de genre temps ; t croît strictement le long de toute courbe causale dirigée vers le futur.
  => la région extérieure (r > r+) est stablement causale : AUCUNE courbe temporelle fermée n'y passe.
  balayage numérique (20 000 points, 0 ≤ a, Q, a²+Q² < M², r > r+) : min de N/r⁴ = 1.000 > 0
  [temps écoulé 21 s]

[A6] Sans hypothèse d'horizon (correction n° 19) : temps de Kerr-Schild  dt_KS = dt + (2Mr - Q²)/Δ dr
  g^{tt}_KS = g^{tt} + [(2Mr - Q²)/Δ]² g^{rr} = -(1 + (2Mr - Q²)/Σ) : identité vérifiée
  => t_KS est une fonction temporelle partout où Σ + 2Mr - Q² > 0, y compris sur le feuillet r < 0 et SANS horizon ;
     elle ne cesse de l'être que dans le tube (r + M)² + a² cos²θ <= M² + Q² entourant l'anneau (taille fixée par M et Q, pas par a).
     Toute courbe causale fermée d'un Kerr-Newman sur-extrémal doit donc traverser ce tube.
  [temps écoulé 21 s]
