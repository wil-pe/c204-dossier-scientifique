[D3] Identité a = c² ∇ ln N pour un observateur statique (métrique statique quelconque, partie spatiale diagonale)
  a_i - ∂_i ln N = [0, 0, 0]  -> identité vérifiée (c = 1)
  Conséquence : entre deux horloges statiques A et B, ln(N_B/N_A) = ∫_A^B ∇ln N · dl  ≤  ∫ |a| dl / c²
   |a| ≤ 1.5 g sur L = 3.0 m  =>  Γ - 1 ≤ 4.91e-16   (revendiqué : 8,8e4)
   |a| ≤ 2.0 g sur L = 3.0 m  =>  Γ - 1 ≤ 6.55e-16   (revendiqué : 8,8e4)
   |a| ≤ 1.5 g sur L = 3.7 m  =>  Γ - 1 ≤ 6.06e-16   (revendiqué : 8,8e4)
   |a| ≤ 2.0 g sur L = 3.7 m  =>  Γ - 1 ≤ 8.07e-16   (revendiqué : 8,8e4)
   pour ln Γ = 11.38 sur L = 3.0 m : accélération moyenne requise = 3.41e+17 m/s² = 3.5e+16 g
   pour ln Γ = 11.38 sur L = 3.7 m : accélération moyenne requise = 2.76e+17 m/s² = 2.8e+16 g

[D4] Bornes par les conditions d'énergie (G = c = 1)
  coquille mince : σ = (1 - k)/(4πR) ; p = [(1 - M/R)/k - 1]/(8πR) = (k**2 - 2*k + 1)/(16*pi*R*k)  avec k = sqrt(1 - 2M/R)
   p/σ = (1 - k)/(4*k)
   condition d'énergie dominante p ≤ σ  <=>  k ≥ [1/5]  =>  Γ_intérieur = 1/k ≤ 5  (R ≥ 25/24 r_s)
  étoile homogène : lapse central N_c = (3k - 1)/2 ; p_c/ρ = (1 - k)/(3k - 1) ; p_c ≤ ρ  <=>  k ≥ [1/2]  => Γ_centre = 1/N_c ≤ 4
   (borne de Buchdahl : p_c -> ∞ quand k -> 1/3, soit R -> 9/8 r_s ; Γ de surface ≤ 3)
